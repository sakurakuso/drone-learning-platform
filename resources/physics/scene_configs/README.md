# 场景配置参考

propwash/default.json5、playground.json5、issum.json5 为上游原始配置，包含动力参数、地图路径和出生点。保留代码 MIT 许可见 ../models/propwash/LICENSE.upstream。对应 GLB 未镜像到本目录，加载还需上游模型与代码；模型独立采用 CC BY 等许可，不能因 JSON5 是 MIT 就忽略模型授权。

[地图目录](https://github.com/mqnc/propwash/tree/main/assets/maps)、[资产署名与许可](https://github.com/mqnc/propwash#attributions)、[RCForge 场景数据](https://github.com/adithya-s-k/RCForge/blob/main/public/scenery/README.md)。地形高度用于显示与实际碰撞需分开评估。
