# UIUC 低速翼型风洞测试数据 (SoarTech 8)

## 数据来源

**来源**: UIUC Applied Aerodynamics - Low-Speed Airfoil Tests (SoarTech 8)
**网址**: https://m-selig.ae.illinois.edu/uiuc_lsat.html
**测试时间**: 1987-1988 年（普林斯顿大学）
**包含翼型**: 54 个

---

## 数据格式说明

### 原始文件 (*.06, *.08, *.10)
- `.06` = 雷诺数 60,000
- `.08` = 雷诺数 80,000
- `.10` = 雷诺数 100,000

### CSV 文件 (*.csv)
每个 CSV 文件包含：
- **alpha**: 迎角（度）
- **Cl**: 升力系数

## 文件夹结构

```
UIUC_空气动力学数据/
├── README.md              # 本文档
├── CSV_data/             # CSV 格式数据（alpha, Cl）
│   ├── E387A_Re06.csv
│   ├── E387A_Re08.csv
│   ├── E387A_Re10.csv
│   └── ... (共 110 个 CSV 文件)
├── *.06, *.08, *.10     # 原始数据文件
├── *.COR                 # 翼型坐标文件
├── ALL.DAP              # 所有翼型数据汇总
├── ALL.PD               # 所有翼型极曲线数据
└── LIFT.LOG             # 升力相关日志
```

## 无人机适用推荐

| 应用 | 推荐翼型 | 理由 |
|------|----------|------|
| 高升力 | SD7003, S3021 | 最大升力系数高 |
| 耐摔/通用 | E387, CLARK-Y | 气动特性稳定 |
| 高速 | SD8000, SD8020 | 低阻力 |
| 滑翔 | SD7032, SD7062 | 滑翔比高 |
