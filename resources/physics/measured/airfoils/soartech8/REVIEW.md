# SoarTech 8 说明核对与数据异常

[提供的中文 README](references/supplied_README.md)原样保留作为参考；数值和条件以原始数据为准。

| 项目 | 核对结果 | 处理 |
| --- | --- | --- |
| CSV 有 Cd/Cm/Cp 列 | 107 个非空 CSV 中三列全部为空 | 保留原 CSV；统一升力表只输出实际字段；阻力另从 ALL.PD 提取 |
| 110 个 CSV | 3 个只有表头，没有记录 | 放入 quarantine/empty_csv，排除统一表 |
| README 雷诺数表格 | 多行文件后缀与列名错位，例如 E205B 的 60k 栏写 .04 | 使用原始实际 Re；名义值另列，不凭表格推断 |
| E387A 示例 | README 例表写 alpha=0、Cl=0.15；原文件邻近点为 (-0.39,0.15) 与 (0.03,0.21) | 原说明仅作参考，统一表提取原始实测点 |
| ALL.PD 第 551 行 | DF103 配置阻力字段包含控制字符，官方原文件亦如此 | 原文件保持不变；该点隔离，未猜测修正或填 0 |
| ALL.PD 文件结尾 | 旧 DOS 结束标记 | 解析只读取正式配置块 |
| 耐摔推荐 | 气动曲线不能证明结构抗冲击能力 | 不作为选型依据 |
| 数据许可 | 官方及提供的 ZIP 未见独立许可文本 | 单列为待核，不继承其他卷册许可 |

异常点的原行、源行号、配置与 Re 见 [polar_anomalies.csv](quarantine/polar_anomalies.csv)。要修正该点，应核对原书图表或取得作者确认；仅删除控制字符可能把错误字段误写成有效值。

提供的 107 个有效 CSV 覆盖 38 个文件名变体，且只转换了部分名义 Re 文件。新的 lift.csv 则覆盖全部 135 个原始升力文件。数据不按迎角排序或去重，避免无意丢失滞回和重复测量信息。
