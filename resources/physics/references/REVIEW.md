# 提供资料的核对结果

结论：值得保留，作为低速翼型数据的检索线索。原稿单独留存，本文件指出限制；应用时以官方原数据和测试条件为准。

| 原稿内容 | 核对结果 |
| --- | --- |
| 200 多个翼型 | 官方介绍支持这个总量；不同卷册有重复翼型，不能简单相加 |
| Vol 1–4 的年份、页数、翼型数与 Re 范围 | 与官方介绍一致 |
| Vol 5 17+ | 官方给出具体翼型与构型清单，应按清单使用，不把构型数混为独立翼型数 |
| Vol 6 | 官方对应 Williamson 2012 硕士论文，数据文件夹为 volume06；不与正式五卷书籍混称 |
| SoarTech 8 | 54 个翼型、Re 60000–300000；1987–1988 是普林斯顿测试年份，不等同书籍出版年份 |
| S9104 的 Cl 约 2.6 | 官方明确是 XFOIL 预测，Re 200000；没有据此确认其风洞实测 |
| S1223 所属 Vol 2、5 | 官方介绍明确首次见于 Vol 1，Vol 5 有 Gurney 构型；原稿卷册信息须逐项复核 |
| E387/S7012 耐摔 | 气动数据不能证明机体耐撞或结构强度 |
| S822/S834 NREL 认证 | NREL 报告中的测试不等于产品认证；应改称有公开风洞测试资料 |
| 高速、通用翼型推荐 | 未固定雷诺数、构型和任务条件，保留为待验证判断 |
| PDF 下载链接 | 原稿中的 Low-Speed-Airfoil-Data-V*.pdf 与当前官方入口不同；使用下方官方索引的链接 |

翼型坐标、二维翼型极曲线、有限翼系数、旋翼推进数据、整机阻力必须分别处理。四旋翼优先用桨型推进数据与整机参数，不能将某翼型 Cd 直接设成整个无人机阻力系数。

来源：[UIUC LSATs](https://m-selig.ae.illinois.edu/uiuc_lsat.html)、[数据下载与许可](https://m-selig.ae.illinois.edu/pd.html)、[S9104 预测](https://m-selig.ae.illinois.edu/uiuc_lsat/s9104/s9104.html)。
